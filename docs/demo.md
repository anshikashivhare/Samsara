# Demo Flow

1. Start the Docker development stack.
2. Create an incident.
3. Load a sample satellite scene.
4. Run segmentation and inspect the spill polygon.
5. Run drift hindcast to generate probable origin zones.
6. Load sample AIS observations.
7. Build trajectories and calculate behavioural anomalies.
8. Run attribution and inspect ranked candidates.
9. Open the dashboard and review map layers, confidence, scores, and evidence timeline.

For a hackathon demo, keep a small reproducible sample dataset under `data/sample/` and document its provenance.
